# Home Safety Walkthrough

A Labster-style occupational therapy simulation: an entry-level OTD student walks a client's single-story apartment after her hip replacement, inspects, flags, and measures fall hazards, then submits an assessment for a scored debrief.

Play: https://keifp.github.io/home-safety-sim/

Built in Unity 6 (URP). Source lives in the LabSkillsGame project (scene `HomeSafetyScene`); this repo holds the WebGL build served by GitHub Pages from `docs/`.

Controls: WASD move, mouse look, click to capture the mouse, Esc to release. Look at an object: 1 = Inspect, 2 = Flag as hazard, 3 = Measure. Tab = submit assessment, R = restart.
